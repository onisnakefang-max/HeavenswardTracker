# Heavensward Tracker

Основа плагина Dalamud для отслеживания пройденных заданий Heavensward (3.0–3.5) через IPC-плагин Tsukimichi.
Откройте окно командой `/hwtracker` или через меню Dalamud.

## Текущее состояние

Плагин требует установленный и запущенный Tsukimichi (внешний репозиторий: `https://raw.githubusercontent.com/xenofei/Tsukimichi/main/pluginmaster.json`). Названия и строки каталога загружаются из Quest Excel sheet установленного игрового клиента через Lumina, поэтому язык берётся из клиента. Прогресс по персонажу читается из документированного IPC API Tsukimichi; ранее выполненные задания должны распознаваться автоматически.

Статический каталог названий не поставляется: список строится при запуске из локальных игровых таблиц и отбирается по дополнению Heavensward. Внутри каталога квесты классифицируются по игровым полям задания; новые данные игры автоматически попадут в список после обновления клиента.

В текущей заготовке достижения рассчитаны локально по закрытию каждой категории; официальный список достижений игры не изменяется.

## Сборка

Требуются .NET SDK 10 и SDK Dalamud API 15 (`Dalamud.NET.Sdk`). Откройте файл `HeavenswardTracker/HeavenswardTracker.csproj` в Visual Studio с установленным .NET 10 SDK.
